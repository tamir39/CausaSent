## Setup

- **Tagger**: PhoBERT-large, two parallel heads (aspect-sentiment, cause), VnCoreNLP word segmentation upstream.
- **Action gen**: mT5-base, conditioned on `(aspect, sentiment, cause, review)`.
- **Splits**: 80/10/10 by review id, seed 42.
- **Selection**: best PhoBERT checkpoint by mean entity-F1 on val; best mT5 by val loss.
- **Hardware**: TBD (single GPU; Kaggle P100 / T4 ×2).

Run metadata for every reported number lives under `runs/<timestamp>/`
(config.yaml, git_sha.txt, env.txt, metrics.jsonl).
